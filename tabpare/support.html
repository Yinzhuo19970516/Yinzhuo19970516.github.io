TabPare support

Clear guidance. No mystery.

Learn how Smart organize, Close, Sleep, Undo, and website protection work, and what to check when a result is not what you expected.

Getting started

  1. Install TabPare from the Chrome Web Store and pin it to the toolbar.
  2. Select the TabPare icon to organize eligible tabs in the current window or see the duplicate and inactive candidate counts.
  3. Select Smart organize to create useful groups in the current window. On first use, Chrome asks for optional tab-group permission.
  4. Select the action shown for the cleanup you want: Close for duplicates, or Close inactive / Sleep inactive for inactive tabs. Cleanup starts immediately without a confirmation dialog.
  5. Open Settings to change the inactivity threshold, choose whether inactive cleanup uses Close or Sleep, adjust duplicate matching, choose the manual window scope, protect a website, or configure optional automatic cleanup.

TabPare requires Chrome 121 or later and cannot be enabled in Incognito windows.

Smart organize

Smart organize works on the window where TabPare was opened. It classifies ungrouped normal HTTP or HTTPS tabs, then creates named and colored groups only when at least two tabs belong together. Pinned tabs, browser or extension pages, and tabs already in a group remain untouched.

TabPare always has a deterministic local classifier. If Chrome's on-device language model is already available, it may enhance the local plan. Organization processes only eligible tabs' titles and hostnames; it does not read page content or the full browsing history, and it does not upload organization data.

After grouping, select Undo organization to ungroup the affected tabs and restore their previous order when possible. That snapshot lasts only for the current browser session.

If you decline Chrome's optional tab-group permission, no groups are created. Duplicate and inactive cleanup continue to work normally.

Manual cleanup

Duplicate tabs
TabPare groups tabs with the same HTTP or HTTPS URL. It keeps protected tabs; when no copy is protected, it keeps the most recently used copy and closes the other candidates. The optional tracking-parameter setting described below changes how URLs are compared.
Inactive tabs
TabPare compares each normal web tab's last-accessed time with your chosen threshold. Close is the default action. Choose Sleep to ask Chrome to discard the loaded page while keeping its tab. Chrome reloads the page when you return, and TabPare skips tabs Chrome already reports as discarded. Inactive cleanup is always manual.

Active, pinned, and audible tabs are protected. Exact hostnames you add to the protected-sites list are also excluded. Chrome internal pages and other non-web URLs are excluded from both cleanup types.

Manual counts and cleanup can cover All windows or only the Current window. The current-window option is captured when you open TabPare and never expands to other windows if that window becomes unavailable.

Optional tracking-parameter matching

Ignore tracking parameters is off by default. When it is off, TabPare uses its standard duplicate comparison. When it is on, TabPare ignores these parameter names case-insensitively:

utm_*, gclid, dclid, gbraid, wbraid, fbclid, msclkid, mc_cid, mc_eid, _ga, _gl, yclid, ttclid, twclid, li_fat_id, and igshid.

TabPare never ignores ref, source, si, tag, token, session, or redirect. It preserves every remaining parameter and its original order. The selected rule applies to manual and scheduled duplicate cleanup.

Undo the latest cleanup

After TabPare closes tabs, select Undo beside the latest result to reopen them. If only some tabs can be restored, select Retry to try the remaining tabs again.

Undo restores each URL in the background and approximates its previous window and tab order. Chrome does not provide enough information to restore back/forward history, form contents, scroll position, or other in-page state.

Sleep does not offer Undo because it keeps tabs open. The undo option lasts until another cleanup begins, including a Sleep cleanup, Chrome restarts, or the extension is reloaded, updated, disabled, or removed.

Automatic cleanup

  • Automation is off by default.
  • Two hours is the recommended preselected interval, but nothing runs until you enable Automatic cleanup.
  • Preset choices range from 30 minutes to one week. The custom option accepts whole-number intervals within the same range.
  • Scheduled cleanup closes duplicate tabs only. It never closes inactive tabs in the background.
  • Scheduled cleanup always checks all Chrome windows, even when manual cleanup is set to Current window.
  • Scheduling works while Chrome is running. A missed alarm may run after Chrome or the computer wakes.

Troubleshooting

The count is lower than expected
Check whether a tab is active, pinned, playing audio, uses a protected hostname, or has a non-HTTP(S) address. Also confirm whether manual cleanup is set to Current window. Those tabs may be protected or outside the selected scope.
A duplicate remains open
A protected copy is kept. Tabs may also change between the count and the final safety check, in which case TabPare skips the tab. Check whether Ignore tracking parameters is enabled and whether the URLs still differ by a parameter TabPare preserves.
An inactive tab is not counted
Confirm the inactivity value and unit in Settings. Chrome must provide a valid last-accessed time, and the tab must have remained unused past the threshold. In Sleep mode, tabs Chrome already reports as discarded are not counted again.
Automatic cleanup did not run
Confirm that Automatic cleanup is enabled and Chrome is running. Disabling the switch removes the scheduled alarm.
Undo is not available
Undo appears only after a cleanup closes at least one tab. Sleep does not offer Undo. Any new cleanup clears the previous Undo, and it is also cleared when Chrome restarts or the extension is reloaded, updated, disabled, or removed.
Smart organize did not create groups
Confirm that Chrome granted the optional tab-group permission and that the current window contains at least two related, ungrouped normal web tabs. Pinned, internal, and already grouped tabs are intentionally preserved. Cleanup does not depend on this permission.
Undo organization is not available
Undo organization appears only after TabPare creates a group. It lasts for the current browser session and is cleared when Chrome restarts or the extension is reloaded, updated, disabled, or removed.
The extension stopped responding
Open chrome://extensions, confirm TabPare is enabled, then restart Chrome. If the problem continues, include your Chrome version and steps to reproduce when contacting support.

Contact support

Use the Support hub on TabPare's Chrome Web Store listing and include:

  • Your Chrome version and operating system.
  • The TabPare version shown on chrome://extensions.
  • What you expected, what happened, and reproducible steps.

Do not send private browsing history, account credentials, or screenshots containing sensitive tab titles or URLs.
