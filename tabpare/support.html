TabPare support

Clear guidance. No mystery.

Learn what each cleanup does, how scheduling works, and what to check when a count or cleanup is not what you expected.

Getting started

  1. Install TabPare from the Chrome Web Store and pin it to the toolbar.
  2. Select the TabPare icon to see the current duplicate and inactive candidate counts.
  3. Select Close for the cleanup you want. Cleanup starts immediately without a confirmation dialog.
  4. Open Settings to change the inactivity threshold or configure optional automatic cleanup.

TabPare requires Chrome 121 or later.

Manual cleanup

Duplicate tabs
TabPare groups tabs with the same HTTP or HTTPS URL. It keeps protected tabs; when no copy is protected, it keeps the most recently used copy and closes the other candidates.
Inactive tabs
TabPare compares each normal web tab's last-accessed time with your chosen threshold. Only manual cleanup can close inactive tabs.

Active, pinned, and audible tabs are protected. Chrome internal pages and other non-web URLs are excluded from both cleanup types.

Automatic cleanup

  • Automation is off by default.
  • Two hours is the recommended preselected interval, but nothing runs until you enable Automatic cleanup.
  • Preset choices range from 30 minutes to one week. The custom option accepts whole-number intervals within the same range.
  • Scheduled cleanup closes duplicate tabs only. It never closes inactive tabs in the background.
  • Scheduling works while Chrome is running. A missed alarm may run after Chrome or the computer wakes.

Troubleshooting

The count is lower than expected
Check whether a tab is active, pinned, playing audio, or uses a non-HTTP(S) address. Those tabs are excluded or protected.
A duplicate remains open
A protected copy is kept. Tabs may also change between the count and the final safety check, in which case TabPare skips the tab.
An inactive tab is not counted
Confirm the inactivity value and unit in Settings. Chrome must provide a valid last-accessed time, and the tab must have remained unused past the threshold.
Automatic cleanup did not run
Confirm that Automatic cleanup is enabled and Chrome is running. Disabling the switch removes the scheduled alarm.
The extension stopped responding
Open chrome://extensions, confirm TabPare is enabled, then restart Chrome. If the problem continues, include your Chrome version and steps to reproduce when contacting support.

Contact support

Use the Support hub on TabPare's Chrome Web Store listing and include:

  • Your Chrome version and operating system.
  • The TabPare version shown on chrome://extensions.
  • What you expected, what happened, and reproducible steps.

Do not send private browsing history, account credentials, or screenshots containing sensitive tab titles or URLs.
