TabPare privacy

Privacy Policy

How TabPare handles information while identifying and closing duplicate and inactive Chrome tabs.

Scope

This policy applies to the TabPare Chrome extension.

Effective date
August 29, 2026

Information processed

To provide its cleanup features, TabPare reads information about tabs currently open in Chrome:

  • The tab URL, to group matching pages and restrict cleanup to normal HTTP or HTTPS pages.
  • The tab's last-accessed time, to identify inactive tabs and choose which duplicate to keep.
  • Whether the tab is active, pinned, or playing audio, so protected tabs are not closed.
  • The tab identifier, so Chrome can close the selected candidate.

This information is processed temporarily on the user's device. TabPare does not persist tab URLs, page content, page titles, or a browsing-history log.

Settings and local records

TabPare stores only the information needed to remember user choices and report the latest cleanup:

  • Chrome Sync storage: whether automatic cleanup is enabled, the selected automatic-cleanup interval, and the manual inactivity threshold and unit. Chrome may sync these settings through the user's signed-in Chrome profile when Chrome Sync is enabled.
  • Local extension storage: one aggregate record for the most recent cleanup, including its trigger, cleanup type, timestamps, and counts of closed, skipped, or failed tabs. This record contains no tab URLs.

How information is used

Tab information and saved settings are used solely to provide the user-facing functions described in the Chrome Web Store listing: count and manually close duplicate or inactive tabs, protect active, pinned, or audible tabs, and run optional scheduled duplicate cleanup after the user enables it.

No developer collection or sharing

TabPare has no developer-operated data server, advertising SDK, or analytics SDK. The extension does not sell, share, or transmit browsing activity or settings to the operator or to third parties. It does not use information for advertising, creditworthiness, lending, or any purpose unrelated to tab cleanup.

Your controls and retention

  • Automatic cleanup is off by default and can be disabled at any time in TabPare settings.
  • Settings remain in Chrome extension storage until changed, cleared through Chrome, or removed with the extension, subject to Chrome Sync behavior.
  • The local aggregate cleanup record is replaced after a later cleanup and can be removed by clearing the extension's stored data or uninstalling TabPare.

Chrome permissions

tabs
Reads the state of currently open tabs and closes selected candidates.
storage
Saves cleanup settings and the most recent aggregate cleanup result.
alarms
Schedules duplicate cleanup at the interval explicitly enabled and selected by the user.

TabPare does not request access to all website content, bookmarks, Chrome browsing history, downloads, or the user's identity.

Limited Use

TabPare's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes and contact

If TabPare's data practices change, this policy and the Chrome Web Store disclosures will be updated before the change is released. Questions can be submitted through the Support hub on TabPare's Chrome Web Store listing.
