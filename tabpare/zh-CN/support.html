TabPare 支持

操作清楚，结果可预期。

了解智能整理、关闭、休眠、撤销和网站保护如何工作，以及结果不符合预期时应检查什么。

开始使用

  1. 从 Chrome 网上应用店安装 TabPare，并将它固定到工具栏。
  2. 点击 TabPare 图标，整理当前窗口中符合条件的标签页，或查看重复标签页和闲置标签页的待处理数量。
  3. 点击智能整理，在当前窗口中创建有用的标签组。首次使用时，Chrome 会询问是否授予可选的标签组权限。
  4. 点击相应操作：对重复标签页选择关闭；对闲置标签页选择关闭闲置或休眠闲置。操作会立即开始，不会再次弹出确认。
  5. 展开设置，可修改闲置判定时间、选择关闭或休眠、调整重复页面比较规则、选择手动清理的窗口范围、保护网站，或配置可选的自动清理。

TabPare 需要 Chrome 121 或更高版本，且无法在无痕窗口中启用。

智能整理

智能整理只处理打开 TabPare 时所在的窗口。它会对尚未分组的普通 HTTP 或 HTTPS 标签页进行分类，并且只有至少两个标签页适合归为一组时才创建带名称和颜色的标签组。固定标签页、浏览器或扩展程序页面，以及已有标签组中的标签页均保持不变。

TabPare 始终提供确定性的本地分类规则。如果 Chrome 的设备端语言模型已经可用，也可用它优化本地分组方案。整理只处理符合条件的标签页标题和域名，不读取网页正文或完整浏览历史，也不会上传整理数据。

分组完成后，可点击撤销整理，尽可能取消受影响标签页的分组并恢复原始顺序。该记录仅保留在当前浏览器会话中。

如果你拒绝 Chrome 的可选标签组权限，TabPare 不会创建标签组；重复和闲置标签页清理仍可正常使用。

手动清理

重复标签页
TabPare 比较相同的 HTTP 或 HTTPS URL。受保护标签页会被保留；没有受保护副本时，会保留最近使用的标签页并关闭其他候选项。下方的可选追踪参数设置会改变 URL 的比较方式。
闲置标签页
TabPare 将普通网页标签页的上次访问时间与所选阈值比较。默认操作是关闭；也可选择休眠，让 Chrome 卸载页面但保留标签页，返回时由 Chrome 重新加载。Chrome 已报告为休眠的标签页不会被再次处理。闲置清理始终需要手动执行。

活动、固定和正在播放声音的标签页会受到保护。加入受保护网站列表的精确域名也会被排除。Chrome 内部页面和其他非普通网页地址不会参与两类清理。

手动统计和清理可以覆盖所有窗口，也可以仅覆盖当前窗口。当前窗口在打开 TabPare 时确定；如果该窗口随后不可用，TabPare 会返回错误，绝不会静默扩大到其他窗口。

可选的追踪参数比较

忽略追踪参数默认关闭。关闭时，TabPare 使用标准重复页面比较；开启后，比较参数名时不区分大小写，并忽略以下参数：

utm_*、gclid、dclid、gbraid、wbraid、fbclid、msclkid、mc_cid、mc_eid、_ga、_gl、yclid、ttclid、twclid、li_fat_id、igshid。

TabPare 不会忽略 ref、source、si、tag、token、session 或 redirect。其余参数及其原始顺序都会保留。手动和定时重复标签页清理使用同一规则。

撤销最近一次清理

TabPare 关闭标签页后，可点击最近一次结果旁的撤销重新打开标签页。如果只恢复了一部分，可点击重试，仅再次恢复尚未成功的标签页。

撤销会在后台重新打开 URL，并尽可能恢复原窗口和标签页顺序。Chrome 无法提供足够的信息来恢复前进或后退历史、表单内容、滚动位置及其他页面内部状态。

休眠不会关闭标签页，因此不提供撤销。开始任何新的清理（包括休眠清理）、Chrome 重启，或扩展被重新加载、更新、停用或移除后，撤销入口都会失效。

自动清理

  • 自动清理默认关闭。
  • 推荐间隔预设为每 2 小时，但只有开启自动清理重复标签页后才会执行。
  • 预设间隔覆盖 30 分钟至 1 周；自定义间隔也必须在这一范围内，并使用整数。
  • 定时清理只关闭重复标签页，绝不会在后台关闭闲置标签页。
  • 即使手动清理范围设为“当前窗口”，定时清理仍会检查所有 Chrome 窗口。
  • 定时任务仅在 Chrome 运行时工作；Chrome 或电脑唤醒后，可能补执行一次错过的任务。

故障排查

待处理数量比预期少
检查标签页是否为当前活动页、已固定、正在播放声音、使用受保护域名，或地址不是 HTTP/HTTPS。还要确认手动清理范围是否为“当前窗口”。这些标签页可能受到保护，或不在当前范围内。
仍有重复标签页未关闭
受保护的副本会保留。统计完成后，标签页状态也可能发生变化；最终安全检查发现变化时，TabPare 会跳过该标签页。请检查是否开启“忽略追踪参数”，以及 URL 是否仍存在 TabPare 会保留的业务参数差异。
闲置标签页没有计入
确认“设置”中的闲置时间和单位。Chrome 必须提供有效的上次访问时间，且标签页未使用时长需要超过阈值。休眠模式下，Chrome 已报告为休眠的标签页不会再次计入。
自动清理没有运行
确认“自动清理重复标签页”已开启，并且 Chrome 正在运行。关闭开关会移除定时任务。
没有显示撤销
只有清理实际关闭至少一个标签页后才会显示撤销。休眠不提供撤销。任何新清理都会清除上一次撤销；Chrome 重启，或扩展被重新加载、更新、停用或移除时也会清除。
智能整理没有创建标签组
确认 Chrome 已授予可选的标签组权限，并且当前窗口中至少有两个相关的、未分组的普通网页标签页。固定标签页、内部页面和已有标签组会被保留。清理功能不依赖此权限。
没有显示撤销整理
只有 TabPare 实际创建标签组后才会显示“撤销整理”。它仅在当前浏览器会话中有效；Chrome 重启，或扩展被重新加载、更新、停用或移除时会清除。
扩展程序停止响应
打开 chrome://extensions，确认 TabPare 已启用，然后重启 Chrome。如果问题仍然存在，联系支持时请提供 Chrome 版本和可复现步骤。

联系支持

请通过 TabPare 在 Chrome 网上应用店商品详情页中的“支持”入口提交问题，并附上：

  • Chrome 版本和操作系统。
  • chrome://extensions 中显示的 TabPare 版本。
  • 你的预期、实际结果和可复现步骤。

请勿发送私人浏览历史、账号凭据，或包含敏感标签页标题和 URL 的截图。
