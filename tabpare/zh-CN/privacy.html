TabPare 隐私

隐私政策

了解 TabPare 在整理、识别、关闭、休眠、保护和恢复 Chrome 标签页时如何处理信息。

适用范围

本政策适用于 TabPare Chrome 扩展程序。

生效日期
2026 年 8 月 30 日

处理的信息

TabPare 安装时不会获得标签页访问权限。在 Chrome 弹出可选授权请求前，弹窗会先说明：TabPare 只检查当前打开的标签页、不读取完整浏览历史、不统计网站停留时长，并且所有标签页数据只在本机处理。只有用户主动点击启用标签页清理后，TabPare 才能读取 Chrome 当前已打开标签页的以下信息：

  • 符合智能整理条件的标签页标题和域名，用于对当前窗口中尚未分组的普通网页标签页进行分类。
  • 标签页 URL，用于识别重复页面，并将整理和清理限制在普通 HTTP 或 HTTPS 页面。如果用户开启“忽略追踪参数”，TabPare 会在本地比较时移除已识别的追踪参数，同时保留其余参数及原始顺序。
  • 标签页上次访问时间戳，用于识别闲置标签页，以及确定重复页面中应保留的副本。TabPare 只将时间戳与用户选择的闲置阈值比较，不会计算用户在网站上的停留时长。
  • 标签页是否处于活动、固定、播放声音、已休眠或已分组状态，用于显示当前范围统计、将 Chrome 已休眠标签计入手动关闭、避免再次休眠这些标签、排除受保护标签，并让智能整理保留固定标签页和已有标签组。
  • 标签页及窗口标识和标签页位置，用于让 Chrome 对指定标签页执行分组、关闭或休眠，将操作限制在指定窗口，并恢复最近一次可撤销操作。

这些信息只在用户设备上处理。智能整理仅处理符合条件的已打开标签页的标题和域名，不读取网页内容，也不读取用户的完整浏览历史。TabPare 的确定性分类规则无需网络服务；如果 Chrome 的设备端语言模型已经可用，TabPare 可能使用该浏览器能力优化本地分组方案。

TabPare 只会在 Chrome 的扩展程序内存会话存储中，临时保存撤销操作所需的元数据。它不会保存网页内容、浏览历史记录、前进或后退历史、表单内容或账号凭据。

设置和本地记录

TabPare 只保存记住用户选择和显示最近一次清理结果所需的信息：

  • Chrome 同步存储：是否开启自动整理或自动清理重复标签页、共用的自动化间隔、手动闲置判定时间及单位、闲置处理使用关闭还是休眠、重复页面比较是否忽略已识别的追踪参数，以及手动清理覆盖所有窗口还是当前窗口。用户登录 Chrome 且开启 Chrome 同步时，Chrome 可能通过用户的 Chrome 个人资料同步这些设置。
  • 本地扩展存储：用户选择的精确受保护域名，以及最近一次清理或撤销操作的一条汇总状态。汇总状态包含时间、操作类型和数量，但不包含标签页 URL。受保护域名不会保存到 Chrome 同步存储。
  • 内存会话存储：清理关闭标签页后，临时保存撤销所需的 URL 和窗口位置信息；智能整理创建标签组后，临时保存撤销整理所需的标签页标识和原始位置。这些信息不会同步，也不会发送给开发者或第三方。

信息用途

标签页信息和保存的设置仅用于提供 Chrome 网上应用店商品说明中列出的功能：显示所选范围内的已打开标签和 Chrome 已休眠标签数量；按用户操作或可选的自动计划整理符合条件的标签页并撤销最近一次整理；统计并手动关闭重复或闲置标签页；通过 Chrome 的标签页卸载能力休眠闲置页面；按用户选择的规则比较重复 URL；将手动清理限制在所选窗口范围；保护活动、固定、播放声音或用户指定网站的标签页；恢复最近一次关闭标签页的清理；以及在用户主动开启后定时清理重复标签页。

“忽略追踪参数”默认关闭。开启后，比较参数名时不区分大小写，并忽略：utm_*、gclid、dclid、gbraid、wbraid、fbclid、msclkid、mc_cid、mc_eid、_ga、_gl、yclid、ttclid、twclid、li_fat_id 和 igshid。TabPare 不会忽略 ref、source、si、tag、token、session 或 redirect。手动和定时重复标签页清理使用同一规则，其余参数均保留原始顺序。

开发者不收集，也不共享

TabPare 没有开发者运营的数据服务器，也不包含广告或分析 SDK。扩展程序不会向开发者或任何由开发者选择的外部服务出售或发送标签页标题、域名、URL、整理方案、浏览活动或设置。用户开启 Chrome 同步后，Chrome 仅可能通过该用户的 Chrome 个人资料同步上文列出的偏好设置。TabPare 不会将相关信息用于广告、信用评估、贷款或任何与标签页整理和清理无关的用途。

你的控制权与保留期限

  • 自动整理和自动清理重复标签页均默认关闭，可随时在 TabPare 设置中关闭。
  • TabPare 无法在无痕窗口中启用。
  • 手动智能整理只在用户点击后运行；自动整理只在用户主动开启后运行。创建标签组前 Chrome 会请求可选的标签组权限；拒绝权限后，清理功能仍可使用。
  • 关闭是默认的闲置处理方式。用户也可选择休眠，让 Chrome 卸载已加载页面但保留标签页；返回该标签页时，Chrome 会重新加载页面。
  • 设置会保存在 Chrome 扩展存储中，直到用户修改设置、通过 Chrome 清除扩展数据或卸载扩展；Chrome 同步行为另受用户个人资料设置影响。
  • 精确受保护域名会保存在本地扩展存储中，直到用户移除保护、清除扩展数据或卸载 TabPare。
  • 本地清理汇总记录会在后续清理后被替换，也可通过清除扩展数据或卸载 TabPare 删除。
  • 休眠不会生成清理撤销记录。新的清理开始时（包括休眠清理）、Chrome 重启时，或扩展被重新加载、更新、停用或移除时，内存中的清理撤销记录会被清除。
  • 整理撤销记录仅保留在当前浏览器会话中；Chrome 重启，或扩展被重新加载、更新、停用或移除时会被清除。

Chrome 权限

tabs（可选）
只在用户点击启用标签页清理后申请。读取当前已打开标签页的标题、域名或 URL、状态、分组和位置，以便 TabPare 对符合条件的标签页分类、识别清理候选项、关闭或休眠选中的标签页，并恢复可撤销操作。
storage
保存清理设置、精确受保护域名、最近一次清理的汇总结果，以及临时的内存撤销记录。
alarms
按用户明确开启并选择的间隔，定时执行本地标签整理、重复标签页清理或两者。
tabGroups（可选）
用户点击“智能整理”或开启“自动整理标签页”后，用于创建、命名、着色和撤销 Chrome 标签组。Chrome 会在使用前询问此可选权限；拒绝权限不会影响清理功能。

TabPare 不会申请访问所有网站内容、书签、Chrome 浏览历史、下载内容或用户身份。

有限使用

TabPare 对通过 Chrome API 获得的信息的使用，遵守 Chrome 网上应用店用户数据政策及其有限使用要求。

政策变更与联系

如果 TabPare 的数据处理方式发生变化，我们会在发布变更前更新本政策和 Chrome 网上应用店中的披露信息。如有问题，请通过 TabPare 在 Chrome 网上应用店商品详情页中的“支持”入口提交。
